# Oracle Referans Veri Deposu (G*Power 3.1.9.7 Ground Truth)

Bu dizin, G*Power 3.1.9.7 uygulamasından doğrudan elde edilen gerçek referans verilerini (ground truth) saklamak için hazırlanmıştır.

## Dizin Yapısı
- `protocols/`: G*Power uygulamasındaki "Protocol of power analyses" sekmesinden kopyalanan ham metin çıktıları (`vector_1.txt`, `vector_2.txt`, vb.).
- `screenshots/`: G*Power arayüzünde hesaplama yapıldıktan sonra alınan ekran görüntüleri (`vector_1.png`, `vector_2.png`, vb.).

> **Kritik Kural:** Buraya yalnızca gerçek G*Power uygulamasından alınan doğrulanmış veriler kaydedilecektir. Tahmini veya sentetik veri girilmez.
