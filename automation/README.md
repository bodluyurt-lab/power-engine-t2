# G*Power GUI Otomasyon Prototipi

Bu dizin, G*Power 3.1.9.7 arayüzünü otomatik kontrol ederek referans veri toplamak için tasarlanmış otomasyon prototiplerini içerir.

## Dosyalar
- `prototype_v1.py`: Tek bir vektör (V1 girdi seti) üzerinde pencere bağlantısı, girdi girişi, hesaplama tetikleme ve protokol okuma adımlarını test eden prototip betik.

## Çalıştırma Gereksinimleri
1. Python 3.12 (Sistemde veya sanal ortamda kurulu olmalıdır).
2. Sanal Ortam Paketleri: `pywinauto`, `pyautogui` (isteğe bağlı).
3. G*Power 3.1.9.7 açık ve ekranda görünür olmalıdır.
